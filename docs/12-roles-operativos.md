# Roles operativos de empleados

Los roles base asignan permisos iniciales y no sustituyen el control individual: el administrador puede conceder o revocar excepciones por empleado.

| Rol | Alcance base |
| --- | --- |
| Administrador | Control total, usuarios, permisos y configuración. |
| Gerencial | Lectura ejecutiva de finanzas, proyectos, inventario y Kardex. |
| Auxiliar administrativo | Consulta y apoyo documental; puede solicitar insumos. |
| Administrativo | Consulta operativa y aprobación técnica de requisiciones. |
| Jefe de almacén / Bodeguero | Control de stock, despachos, devoluciones y custodia. |
| Almacenista | Operación diaria de almacén, despachos y herramientas. |
| Ingeniero residente | Dirección técnica y requisiciones de obra. |
| Maestro de obra / Cuadrilla | Solicitud de materiales en frente de obra. |
| Soldador | Consulta de obra, solicitud de recursos y devoluciones autorizadas. |
| Obrero / ayudante | Consulta de obra y solicitud de insumos autorizados. |
| Auditor / Contador | Consulta de auditoría, costos, inventario y Kardex. |
